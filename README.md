# Onlineshop

A full-stack ecommerce web application built with React and Django Rest Framwork. This project includes user authentication, product management, shopping cart, favorites system, order management, and admin dashboard features.


## Features

- User registration and login
- Product listing and details
- Add to cart fuction
- Favorites
- Order placement and tracking
- Admin dashboard
- Category and trend management
- Responsive design
- Dark Mode support


## Tech Stack

### Frontend
- React
- React Router
- Tailwind CSS
- CoreUI

### Backend
- Django
- Django REST Framework
- SQ Lite
## Installation

### Enviroment Setup

```bash
  cd online-env
  cd Scripts
  activate
```

### Frontend Setup

```bash
  cd onlineshop
  npm install
  npm start
```

### Backend Setup

```bash
  cd shopapi
  pip install -r requirements.txt
  python manage.py runserver
```
